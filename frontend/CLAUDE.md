# Frontend Notes

## 技术栈

- Vue 3
- Pinia
- Vue Router
- TypeScript

## 页面约束

- `/knowledge` 是聊天式主页，不再保留“自由问答 / 本地论文分析 / 在线候选筛选”三栏工作台。
- 聊天页以消息列表和底部输入框为中心，`+` 菜单用于图片、本地 PDF、库内论文选择。
- 页面必须同时兼顾桌面和移动端，不能依赖固定三列宽度。

## 状态管理

- 会话、消息、记忆快照、草稿附件都放在 `knowledge` store。
- 文档上传和轮询仍沿用 `documents` store，不要重复实现上传状态机。

## 交互偏好

- 错误提示优先给用户可理解的业务文案，不要把底层异常直接泄漏到主界面。
- 已附加内容、记忆命中、降级提示要轻量呈现，不要压过主对话内容。
