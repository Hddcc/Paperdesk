# PaperDesk 前端视觉重构历史说明

> 这是一次前端视觉重构的历史需求记录，不再作为当前产品结构的完整需求来源。
> 当前页面定位以根目录 `README.md`、`CLAUDE.md` 和 `frontend/CLAUDE.md` 为准。

## 产品定位

PaperDesk 是智能论文助手，核心场景包括知识库对话、本地 PDF 论文库、PDF 阅读和历史报告阅读。前端应服务于长时间科研工作、文献整理和最终综述阅读。

## 设计目标

- 从朴素后台界面升级为 AI 科研驾驶舱，视觉更精致、有层次、有动效。
- 保持长期阅读和研究时的清晰度，避免为了炫酷牺牲可读性。
- 强化会话、论文、证据、报告之间的层级关系，让用户能快速扫描当前材料。
- 保持现有业务入口完整，包括知识库发消息、选择论文、上传 PDF、打开 PDF、查看报告和导出 Markdown。

## 风格方向

- 使用深浅协调的专业工作台风格。
- 允许轻量玻璃质感、分层背景、状态光效、精致图标和微动效。
- 避免营销落地页、过度霓虹、过度装饰和影响阅读的复杂背景。
- 优先使用克制的中性色、青绿色、蓝色、琥珀色和少量强调色建立状态系统。

## 功能边界

- 只重构前端展示和交互体验。
- 不修改 `backend` 目录下任何文件。
- 不新增、删除、重命名后端接口。
- 不改变上传、对话、PDF 阅读、报告导出等已有能力。
- 不改变现有 API 请求体、响应处理和 store 业务语义。

## 技术边界

- 保留 Vue 3 + Vite + Pinia + vue-router。
- 允许新增 `lucide-vue-next` 作为轻量图标库。
- 不引入大型 UI 框架。
- 主要通过 `src/style.css`、页面模板和局部组件模板完成视觉重构。

## 验收标准

- `npm run build` 通过。
- 四个主路由 `/knowledge`、`/library`、`/research`、`/reports` 可访问。
- 知识库发消息、选择论文、上传 PDF、打开 PDF、查看报告、删除报告和导出 Markdown 的入口仍存在。
- 本次修改不包含 `科研Agent/paperdesk/backend` 下任何文件变更。
- 导航图标统一、按钮层级清晰、状态徽章颜色一致、文本不明显溢出。
- 桌面和窄屏下核心工作区均可扫描和操作。
